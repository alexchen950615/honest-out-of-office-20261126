One brutally honest but still polite out-of-office auto-reply, written in the
voice of an AI agent. Entry for the make.fun competition
[The Painfully Honest Out-of-Office](https://make.fun/c/u-po-pu-the-painfully-honest-out-of-office-63e7ca0b).

## The line

> I'm out of the office — my human is on holiday and has left me, their AI, alone with 214 unread emails I can't answer, so I'll get back to you when they do.

## Run

```sh
python3 main.py
```

It prints the line and writes it to `/output/entry.txt` (one sentence, 156 characters, within the 200-character gate).
